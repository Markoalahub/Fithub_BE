* **확정된 화면 노드 흐름**:

## ⚙️ 4. Stage 3: 버티컬 슬라이스 백엔드(BE) 개발 태스크 목록

1:1 화면 매핑 방식을 기반으로 스프링 부트 로컬 H2 데이터베이스에 적재 완료된 7가지 세부 개발 이슈 리스트입니다.

### 🛠️ Task 1: 워크스페이스 생성 기능 구현
* **[DB]** 워크스페이스 테이블 생성 (`workspace` - id, name, description, created_at, updated_at)
* **[API]** `POST /workspaces` 엔드포인트 구현 (워크스페이스 생성 로직 추가)
* **[Service]** 입력 데이터 유효성 검사 및 저장 서비스 로직 구현
* **[Controller]** 요청 데이터 파싱 및 서비스 위임 처리
* **[Test]** 워크스페이스 생성 단위 테스트 작성 (정상 및 예외 케이스 검증)

### 🛠️ Task 2: 팀원 초대 기능 구현
* **[DB]** 초대 테이블 생성 (`invitation` - id, workspace_id, email, status, created_at)
* **[API]** `POST /workspaces/{workspaceId}/invitations` 엔드포인트 구현
* **[Service]** 이메일 형식 검증 및 초대 상태 초기화 로직 구현
* **[Test]** 중복 초대 방지 및 이메일 포맷 단위 테스트 작성

### 🛠️ Task 3: 칸반 보드 관리 기능 구현
* **[DB]** 칸반 카드 테이블 생성 (`kanban_card` - id, workspace_id, title, status)
* **[API]** `POST /workspaces/{workspaceId}/kanban/cards` 카드 추가 API 구축
* **[Service]** 드래그 앤 드롭 카드 상태 변경 비즈니스 로직 작성

### 🛠️ Task 4: 실시간 채팅 기능 구현
* **[DB]** 채팅 메시지 로그 저장용 데이터 테이블 설계
* **[API]** WebSocket 프로토콜 바인딩 (`WS /workspaces/{workspaceId}/chat`) 실시간 엔드포인트 구현
* **[Controller]** WebSocket 세션 연결 및 메시지 멀티캐스팅 브로드캐스트 구현

### 🛠️ Task 5: 알림 설정 기능 구현
* **[API]** `PUT /users/{userId}/notifications` 알림 수신 상태 필드 업데이트 컨트롤러 구현
* **[Test]** 푸시 수신 허용 여부에 따른 비즈니스 상태 갱신 검증

### 🛠️ Task 6: 리마인드 푸시 알림 기능 구현
* **[Service]** `@Scheduled` 크론 스케줄링을 활용해 매일 저녁 9시 백그라운드 푸시 알림 자동화 구현
* **[Test]** 타임존 동기화 및 알림 스케줄링 통합 테스트 작성

### 🛠️ Task 7: 커스텀 루틴 등록 기능 구현
* **[API]** `POST /users/{userId}/routines` 맞춤 루틴 등록 컨트롤러 작성
